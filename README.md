# finally-lastup — شرکت تعاونی عشایری کوه نور کهگیلویه

نسخه نهایی استاتیک برای انتشار روی GitHub Pages و دامنه اصلی.

- فایل‌ها در ریشه پروژه قرار دارند و هیچ پوشه `assets` یا زیرپوشه‌ای وجود ندارد.
- ترتیب اخبار بر اساس جدیدترین عملکرد/تاریخ انتشار است: ۱۴۰۴، ۱۴۰۴/۰۹، ۱۴۰۳/۱۲، ۱۴۰۰/۱۰.
- دامنه اصلی: `https://tavonikohnoor.ir/`
- فایل `CNAME` برای دامنه اصلی در ریشه پروژه قرار دارد.
- `robots.txt` و `sitemap.xml` برای دامنه اصلی تنظیم شده‌اند.
- اخبار و تصاویر خبرها کاملاً محلی هستند.
- برای سه سند قدیمی، صفحه سند داخل خود بخش «اسناد و مدارک» embed می‌شود؛ منبع تصاویر اصلی آن‌ها در بسته اولیه موجود نبود.
